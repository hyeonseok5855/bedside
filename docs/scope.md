# Scope

## 구현 순서

**수집 워커를 먼저 만든다. 대화 화면은 그다음이다.**

데이터는 쌓이는 데 시간이 걸리지만 UI는 그렇지 않다. 첫 주에 UI 없이
백그라운드 로깅만 하는 스켈레톤을 폰에 깔아두면, 대화 파트가 완성될 때쯤
2~3주치 실제 데이터가 있어서 첫 테스트부터 진짜 하루로 검증할 수 있다.

반대 순서면 대화는 되는데 물어볼 것이 없는 상태로 몇 주를 보낸다.

## v1

목적은 기능 완성이 아니라 가설 검증이다. 검증할 가설은 둘.

1. 음성 대화 루프가 밤에 견딜 만한가
2. AI가 던지는 질문이 실제로 기억을 끌어내는가

여기에 기여하지 않는 것은 전부 잘랐다.

| 영역 | 범위 |
|---|---|
| 수집 | 위치(지오펜스 기반 체류·이동), 사진 **메타데이터만**(시각·장소·장수), Health Connect(몸무게·걸음·수면) |
| 프로필 | `나에 대하여.md` + `인물/이름.md` — 자유 형식, 직접 작성, 통째로 프롬프트 주입 |
| 대화 | 음성(CLOVA STT/TTS) + 텍스트 폴백, VAD, 스트리밍 TTS |
| 사전 준비 | 밤 정해진 시각에 타임라인 브리핑 → 첫 질문 3개 생성 → 알림 |
| 중단/재개 | 매 턴 즉시 커밋, 무응답 타임아웃, 다음 날 이어하기 |
| 산출물 | 1인칭 마크다운 일기 + 원문 transcript 별도 보존 |
| 열람 | 마크다운 렌더링 뷰어 + **직접 수정** |
| 문체 | 최근 일기 3~5편을 스타일 레퍼런스로 주입 |
| 기반 | DB 암호화(SQLCipher), 일기는 사용자 접근 가능 경로에 파일로, 일일 토큰 사용량 로그와 상한 |

### v1에 굳이 넣은 것과 이유

- **일기 직접 수정** — 편의 기능이 아니라 문체 학습의 유일한 경로다.
  수정본이 다음 생성의 few-shot이 된다. 없으면 초반의 어색함이 영원히
  고쳐지지 않는다.
- **DB 암호화** — 기능이 아니라 기반이다. 나중에 넣으면 마이그레이션이
  지옥이고, 그때는 이미 몇 달치 개인 기록이 평문으로 쌓여 있다.
- **일일 사용량 상한** — 루프 버그로 스트리밍이 안 끊기는 사고가 실제로 난다.

## v2

데이터가 쌓인 뒤에야 의미가 생기는 것들.

- 하루 평가(전날·타임라인 대비 관찰) + **주간 회고** ← 사용 패턴상 이쪽이 핵심
- 사진 vision 분석, 대표 이미지 선별
- 프로필 구조화 + AI 제안 → 사용자 승인 → 반영 루프
- 과거 일기 검색 (FTS로 충분, 임베딩은 아직)
- 수집 소스 추가 (앱 사용시간, 캘린더)
- 민감 필드별 "AI에 노출 / 저장만" 토글
- 암호화 백업 export → 로컬 NAS / Syncthing

### v1에서 뺀 이유

- **사진 vision** — "오후 3시쯤 사진 4장 찍었네요, 뭐 찍었어요?"만으로도
  질문 재료로 충분하다. 어차피 답을 아는 건 사용자다. vision이 실제로
  대화를 좋게 만드는지는 써봐야 알고, 비용 대부분이 여기서 나온다.
- **평가 기능** — 2주치도 없이 "이번 주 패턴"을 뽑으면 AI가 지어낸다.
  매일 쓰지 않으므로 의미 있는 비교에는 한 달이 필요하다.
- **과거 일기 검색** — 20편 이하에서는 날짜로 넘겨보면 된다.
- **프로필 자동 갱신** — v1은 직접 쓴다. 그래야 AI가 무엇을 알아야 하는지가
  먼저 정리된다.
- **소스 추가** — 소스가 늘수록 브리핑이 길어지고 질문이 산만해진다.
  셋으로 시작해서 "물어볼 게 없네" 싶을 때 늘린다.
- **노출 토글** — v1에서는 민감한 항목을 프로필에 넣지 않으면 된다.

## v3

연간 회고, 홈 위젯, 알림에서 바로 답하기, `[heavy]` 표시된 주제를 회고에서
다시 꺼내기, 인물 관계 그래프, 카카오톡 연동 재검토.

## 완료 기준

기능 체크리스트가 아니라 사용 결과로 잡는다.

> **2주간 실제로 사용해서, 대화가 성립한 날이 5일 이상 나온다.**

5일이 안 나오면 기능을 더 넣을 것이 아니라 마찰이 어디 있는지 찾아야 한다는
신호다. 그때 나오는 불만이 v2의 진짜 우선순위가 된다.

예상 규모: v1 대략 3~5주. 절반 이상이 음성 파이프라인.
