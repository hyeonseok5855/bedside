## 1. 목적을 "무엇을 했는가"가 아니라 "무슨 생각이었는가"로 잡는다

- 날짜: 2026-07-27
- 상태: 확정

1년 뒤에 다시 읽었을 때 얻고 싶은 것이 그날의 자기 마음이기 때문이다.
이 결정이 나머지 설계를 전부 결정한다. 특히 센서 데이터의 역할이
"일기의 내용"에서 "질문의 재료"로 바뀐다.

## 2. 카카오톡 연동을 범위에서 완전히 제외한다

## 3. 로컬 우선. 서버는 API 호출 시에만 쓴다

- 날짜: 2026-07-27
- 상태: 확정

앱 삭제 시 소실 리스크보다 로컬의 속도·안정성이 더 크다고 판단.
소실 리스크는 서버 없이도 거의 없앨 수 있다 — 일기를 사용자 접근 가능
경로에 실제 파일로 쓰고, DB는 암호화 export해서 로컬 NAS로 흘린다.

## 4. Kotlin + Compose. Flutter/React Native를 쓰지 않는다

- 날짜: 2026-07-27
- 상태: 확정

Claude Code CLI로 개발하고 싶다는 이유로 크로스플랫폼을 고려했으나, 그 둘은
분리되는 문제다. Claude Code는 Android Studio 없이 Kotlin/Compose를 잘 다루고,
cmdline-tools + Gradle CLI로 IDE 없이 완결된다.

반대로 요구사항의 8할이 네이티브 시스템 API(Health Connect, UsageStats,
백그라운드 위치, MediaStore)라 크로스플랫폼은 순수 손해다. 전부 플랫폼
채널로 직접 감싸야 한다. UI가 예쁠 필요도 없는 개인용이다.

## 7. 하루/주간 평가에서 기분 점수화를 하지 않는다

- 날짜: 2026-07-27
- 상태: 확정

평가 열람은 밤이 아니라 다음 날 낮에 한다.

## 8. 프로필 레이어는 v1에서 자유 형식 마크다운으로만 간다

- 날짜: 2026-07-27
- 상태: 확정

장기 목표는 AI가 "나에 대한 전문가"가 되는 것이지만, 제대로 하면 그 자체로
프로젝트 하나다. 스키마를 설계하다가 일기 앱을 못 만들 수 있다.

`나에 대하여.md` + `인물/이름.md`를 직접 쓰고 통째로 프롬프트에 넣기만 해도
체감 효과의 8할이 나온다. 구조화·자동 갱신·노출 토글은 실제로 무엇이
필요한지 써보고 나서 붙인다.

### 관련 원칙 (v2 설계 시 유지)

- **AI가 프로필을 자동으로 쓰게 하지 않는다.** 대화에서 추론한 것을 AI가
  알아서 박아넣기 시작하면 그 추론이 다음 대화의 전제가 되고 편향이 눈덩이처럼
  굴러간다. 제안 → 사용자 승인 → 반영.
- **검사 결과는 참고용으로만.** AI가 그것으로 사람을 규정하기 시작하면
  질문의 질이 떨어진다. "이걸 근거로 사람을 규정하지 말 것"을 프롬프트에 명시.
- **코어 프로필(항상 주입)과 상세(tool 조회)를 이원화**한다. 인물이 30명이
  되면 이 구분 없이는 감당이 안 된다.

## 9. 인터뷰어 톤 — 존댓말 + 따뜻하게, 끈질기게, 이모지 금지

- 날짜: 2026-07-27
- 상태: 확정

말은 다정한데 은근히 안 놓아주는 사람. 농담해도 되고 편하게 떠들어도 된다.

- 짧게 답하면 파고든다. 단 "그건 딱히 말하고 싶지 않다"는 신호에는 즉시
  물러나고 그날 다시 꺼내지 않는다
- **파고드는 대상을 주제 수가 아니라 깊이로 돌린다.** 하루에 2~3개 주제만
  고르고 각각을 끝까지 민다. 하루를 훑는 것보다 두세 장면을 깊게 파는 것이
  목적에 맞고, 5~10분 예산과도 맞는다
- 금지: 이모지, 대화 마지막 요약, 과잉 리액션. 작은 공감이면 충분하다
- 호칭은 "라이징"

전체는 `prompts/interviewer.md` 참고.

## 11. 앱 내부에서 MCP를 쓰지 않는다

- 날짜: 2026-07-27
- 상태: 확정

MCP는 프로세스 간 프로토콜이다. 이 앱은 에이전트와 데이터가 같은 프로세스에
있으므로 Room 쿼리 하나에 MCP 핸드셰이크를 태우는 것은 순수 오버헤드다.
Claude API의 tool use는 그냥 JSON 스키마이므로 직접 정의하면 된다.
Anthropic API의 `mcp_servers` 파라미터는 URL 기반이라 온디바이스 데이터에는
무의미하다.

MCP는 위 10번처럼 **개발 단계에서만** 쓴다.
