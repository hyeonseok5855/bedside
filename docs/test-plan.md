# Test Plan

기능별 테스트 시나리오. 자동화 수준을 표시한다:

- **U** = JVM 유닛 테스트 (`app/src/test`) — 순수 로직, 네트워크는 API 테스트만
- **I** = 계기 테스트 (`app/src/androidTest`) — 실기기(S23+)에서 실행
- **M** = 수동 (실기기에서 사람이 확인) — 센서·권한·백그라운드·이동 필요

실행:
```bash
./gradlew testDebugUnitTest            # U (실제 API 호출 포함, 키 없으면 API 테스트만 스킵)
./gradlew connectedDebugAndroidTest    # I (연결된 기기 필요)
```
